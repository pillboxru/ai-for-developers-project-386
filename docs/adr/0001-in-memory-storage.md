# Данные хранятся в памяти процесса

Типы событий, расписание и бронирования хранятся в памяти бекенда и теряются при перезапуске контейнера. Учебному MVP база не нужна, а без неё проще развёртывание: один контейнер без томов и внешних сервисов. Хранилище спрятано за слоем `repositories/`, поэтому базу можно подключить позже, не меняя сервисы и маршруты.
